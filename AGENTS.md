## Learned Workspace Facts

- This repo is the BK School of Research (BKSR) Next.js App Router frontend for an academic research and publication organization.
- Primary legacy content source is https://bkschoolofresearch.blogspot.com/; migrated Blogger HTML/noise should be cleaned without rewriting factual meaning.
- Admin at `/admin` is the site CMS: local/demo persistence by default (`.data/cms-database.json`), with optional Mongo driver (`CMS_DRIVER=mongo`, `NEXT_PUBLIC_CMS_MODE=mongo`) plus Cloudinary uploads via `/api/media/upload`; access is password then OTP to the configured admin email before the CMS unlocks; public CMS reads go through an allowlist (`src/lib/cms/public-read.ts`); security regression coverage is `pnpm run test:security`; do not treat Mongo/member-auth persistence as production-ready without an explicit migration; local CMS can lag code seed—merge/sync that file after seed updates or new demo content will not appear; when `CMS_DRIVER=mongo`, public pages (including homepage sections) read MongoDB rather than that local file, so records that exist only in the JSON do not render until they are in Mongo; integration notes live in `docs/backend-integration-plan.md`.
